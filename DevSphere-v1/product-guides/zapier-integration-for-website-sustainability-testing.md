# Planning a workflow for repeat website checks

Start by deciding which URLs and device profiles to test. Keep those settings with each result so later runs are comparable. Run the first check manually in [WebInSight](https://insight.myherb.co.il/). For an automation you maintain yourself, consult the [PageSpeed Insights API documentation](https://developers.google.com/speed/docs/insights/v5/get-started) before setting up a recurring job.
