# DevSphere by MyHerb

[MyHerb](https://www.myherb.co.il/) was founded by Aaron Levin. DevSphere brings together the tools we build and the documentation that helps you use them.

## Explore the tools

- [WebInSight](https://insight.myherb.co.il/) checks page speed, data transfer, accessibility and search setup. Run a check, work through a finding, then repeat the check on the same page.
- [PrintLess EcoMetrix](https://ecometrics.myherb.co.il/) compares paper use and costs across plans. Start with your monthly sheet count.
- [EcoShift](https://ecoshift.myherb.co.il/) estimates emissions for an activity using the figures you enter.
- [EcoPrompts](https://prompts.myherb.co.il/) lets you browse and copy prompts for sustainability research and planning.
- [MyHerb Knowledge](https://knowledge.myherb.co.il/) connects sustainability topics to their sources.
- [EcoSense Device Use beta](https://eco.myherb.co.il/) explores device-use habits. We are also developing a separate EcoSense workspace for reviewing sustainability records and tracing figures back to their sources.
